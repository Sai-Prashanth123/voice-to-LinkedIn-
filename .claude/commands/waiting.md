Call `system_status`, then `next_action`.

Tell Josh in two or three sentences:

1. **Anything that happened while he was away.** `system_status` returns unread notices — a post that
   failed to publish, an idea parked, the queue running low, a token about to expire. Nothing else in
   this system will ever mention them, so read them out, then call `mark_notices_read` with their ids
   so they are not repeated next time.
2. **What is waiting on him**, in his words: drafts to look at, ideas that still need his answers,
   a library change to decide.
3. **The one thing worth doing now**, and offer to start it.

No headings, no bullet lists, no tool names. If nothing is waiting, say that plainly — a quiet week
is a real answer, and the system is built to run short rather than pad.

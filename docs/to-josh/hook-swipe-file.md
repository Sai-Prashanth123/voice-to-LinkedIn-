## Read this before using it

**This file is for reading, not for drafting from, and the reason is mechanical.**

`create_draft` refuses any draft that shares a seven-word run with one of Josh's eight
reference writers — that guard is what makes clause 8.3 ("take the shape, never the words")
real rather than aspirational. **These openings are not in that index.** A draft that lifted
a line from this file would not be refused, because nothing here is in the thing that does
the refusing. So the guard that would normally catch a borrowed hook is absent exactly here.

Take the move. Never the sentence. Nothing in the system loads this file, and nothing should.

## What the preview column means

`▮▮▯` is how many of the three lines a reader sees before "see more" the opening itself uses.
Two filled means something else is still visible underneath it; three means the hook is all
they get. **39% of the openings measured fill or overflow those three lines** — that is the
"wall of text" Josh described on 30 October, counted.

The fold is simulated at 42 characters a line and has never been calibrated against a real
phone, so treat the bars as indicative. `×2.4` is reactions against that author's own median
post, so a big account and a small one are comparable.

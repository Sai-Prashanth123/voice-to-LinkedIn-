What Josh asked for

The contract

A system that turns things Josh already says — voice notes, calls, working sessions — into LinkedIn posts that could only have been written by him. The spec attaches to the services agreement, so every must is an acceptance criterion, not a preference.

Three rules are never negotiable, and each is enforced by the database rather than by intent:

The lived experience test

clause 1

Could anyone else have written this? If yes, it fails. Held in an immutable library section the learning loop structurally cannot reach.

No fabrication

9.4

Every claim, quote, number and name must trace to something Josh actually said. Verified mechanically, before any model gets an opinion.

Nothing publishes without Josh

11.2

Four CHECK constraints make an unauthorised published row impossible to store. Tested adversarially — the database refuses all three violation shapes.

What is built

Nine steps, five ways in

Capture — five ways in

Proven

Voice notes, prompted sessions, call transcripts, Claude Code sessions and typed thoughts, all landing in one idea bank. Telegram capture is proven live; the Claude Code agent is written but has never uploaded.

The interview

Proven

Asks until a moment has a scene, a detail and a realisation — then stops and parks rather than padding. Budgets questions, rephrases prompts that never land, and never writes.

The idea bank

Proven

28 tables, 73 row-level policies, and no DELETE policy anywhere: nothing can be destroyed, only killed and labelled. Re-openable, editable without a developer, exportable in full.

Selection

Proven

Five-factor scoring, retelling detection against the published archive, pillar balance, and a queue that runs short and says so rather than dropping the bar.

Drafting & the gate

Unproven

Eight independent checks, each able to reject. The gate demonstrably rejects — but no draft has ever cleared all eight, and on the current free-tier model 10 of 14 calls are rate-limited.

Visuals

Unproven

Rebuilds a diagram as SVG in Josh's brand — structurally incapable of resembling the source. No visual has ever been built; the request is recorded and sweeps in automatically when a vision-capable model exists.

The calendar

Proven

Drafts arrive as drafts. Josh edits in place and marks ready; only that authorises publishing. His edits are read back into the bank automatically.

The learning loop

Proven

Draft-versus-approved measured at approval — needing no LinkedIn. A one-line verdict asked on the taps Josh already makes. Library changes proposed with evidence, approved by him alone, and reversible.

Operations

Proven

Silence alerts, queue warnings, error surfacing, monthly self-reporting — and a system that now tells Josh when it starts using a service he was never told about.

The acceptance tests

Clause 17

Twelve component tests and one finish line. Until this week none had ever been checked — not failed, never run. They are computed from the live database now, and folded into the monthly report Josh already receives.

What is remaining

By who owns it

One purchase unblocks the most

  • An Anthropic key. Unblocks tests 6, 7, 8 and the finish line itself. One gate run needs ~16,000 tokens; the current free tier allows 8,000 a minute.

Ours, and quick

  • Deploy the web app — it has only ever run on localhost, and four clauses require a screen
  • Exercise the export route, the oldest open item in the build
  • Install the Claude Code agent to start its clock

Josh's, and on the critical path

  • The voice guide — 7 of 14 library sections still await him, and this one carries the whole quality argument
  • Pillars, audience, reference posts, visual brand
  • Answering the five moments already asked and left
  • Connecting LinkedIn, which starts two four-week clocks

Before handover

  • Move every account into Josh's name — the migration is rehearsed, not just written
  • Rotate the development keys
  • Record the walkthrough

The critical path is calendar time, not code. Five component tests need two to four weeks of live running, and those clocks have not started. Every day they stay unstarted is a day added to the end, and no amount of building shortens them.
